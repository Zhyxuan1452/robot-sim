# 需求文档：智能巡检机器人（二维仿真）

## 1. 目标

做一个可以在浏览器里操作的巡检机器人仿真：用户在网页上控制机器人移动，
后端负责判断移动是否合法，并在完成一轮巡检后记录结果。

## 2. 功能需求

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 地图展示 | 10×10 网格，包含障碍物与起点标记 |
| F2 | 手动控制 | 上/下/左/右各移动一格，也可用键盘方向键 |
| F3 | 合法性判断 | 目标格越界或为障碍物时移动失败，位置不变 |
| F4 | 状态反馈 | 页面显示当前位置、当前状态、完成轮次 |
| F5 | 轮次记录 | 成功离开起点后返回起点，记一轮（含轮次号与完成时间） |

## 3. 非功能需求

- 单一镜像可运行，暴露 8080 端口
- 健康检查接口 `/health`
- 提供单元测试覆盖核心规则

## 4. 验收标准

| 场景 | 前置条件 | 操作 | 期望结果 |
|---|---|---|---|
| 正常移动 | 机器人 (1,1)，(1,2) 为空 | 发出「下」 | 到 (1,2)，返回 `ok` |
| 撞障碍 | 机器人 (1,1)，(2,1) 是障碍 | 发出「右」 | 留在 (1,1)，返回 `blocked` |
| 出边界 | 机器人 (0,0) | 发出「上」 | 留在 (0,0)，返回 `out_of_bounds` |
| 无效方向 | 任意 | 发出 `northeast` | 位置不变，返回 `invalid_direction` |
| 完成一轮 | 初始状态，0 轮 | 离开起点后返回起点 | 轮次 +1，含轮次号与时间 |
| 不重复计数 | 刚完成一轮 | 刷新页面 / 多次读取状态 | 轮次不变 |
| 无效移动不计数 | 已离开起点 | 撞墙若干次后回起点 | 只按一次正常返回计一轮 |

## 5. 不做的事（本期）

- 多用户、账号体系
- 持久化数据库（当前用内存）
- 真实机器人对接
